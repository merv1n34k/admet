# Dead volume

Calculated from a [dead volume run](../protocols/templates#dead-volume): three
values you measured by hand and entered in the Measurements table.

| Value | Meaning |
|---|---|
| Dead volume | Mean of the three values, µL, ± SD |
| CV | SD / mean |
| 95 % CI | Repeatability-only Student-t interval |
| Entered | The three values |

Every value must be positive. Nothing is copied anywhere: enter the result in the
dead volume column of the [Rig table](../control/calibration#dead-volume) yourself.
